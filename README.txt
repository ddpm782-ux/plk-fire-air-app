ชุดไอคอนแอป "ระบบติดตามไฟป่าและคุณภาพอากาศ PHITSANULOK FIRE & AIR"
================================================================
ไฟล์ในโฟลเดอร์นี้คือ "หน้าเปิดแอป" ที่มีไอคอนและชื่อระบบ ใช้ติดตั้งบนหน้าจอโฮมมือถือ แท็บเล็ต และคอมพิวเตอร์
เมื่อกดไอคอน จะเปิดระบบ (เว็บแอป Apps Script) เต็มหน้าจอเหมือนแอป

ขั้นตอน (ทำครั้งเดียว)
1) เปิดไฟล์ config.js วางลิงก์เว็บแอป (ลงท้าย /exec) ใน window.APP_URL = '...';
2) นำทั้งโฟลเดอร์ขึ้นเว็บฟรี GitHub Pages (ดูขั้นตอนในข้อความแชต) จะได้ลิงก์ เช่น https://ชื่อบัญชี.github.io/plk-fire-air/
3) ส่งลิงก์นี้ให้ผู้ใช้ แล้วติดตั้งไอคอน
   - iPhone/iPad (Safari): ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
   - Android (Chrome): เมนู ⋮ → ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก
   - คอมพิวเตอร์ (Chrome/Edge): ไอคอนติดตั้งท้ายช่องที่อยู่ หรือ เมนู ⋮ → บันทึกและแชร์ → ติดตั้งหน้าเว็บเป็นแอป
4) (แนะนำ) ใน Code.gs ตั้งค่า ICON_URL = 'https://ชื่อบัญชี.github.io/plk-fire-air/icons/icon-192.png' ให้แท็บเบราว์เซอร์ของระบบแสดงไอคอนนี้ด้วย
